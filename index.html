Sobre o Aluno

Sou aluna do CEET Vasco Coutinho, focado no aprendizado e aplicação de tecnologias voltadas para a criação de soluções web modernas e eficientes. Minha jornada abrange estudos aprofundados em estruturação de páginas, estilização avançada de layouts, lógica de programação e interatividade para a experiência do usuário.

Principais matérias e áreas de estudo:

  • Fundamentos de Web Design: Criação de estruturas semânticas e acessíveis (HTML5).
  • Estilização e Layouts Responsivos: Uso de CSS Avançado, Flexbox e CSS Grid para adaptação em diferentes telas.
  • Lógica e Programação Front-End: Desenvolvimento de scripts para comportamento dinâmico de páginas.

Projetos Desenvolvidos

1. Site Institucional Responsivo

Descrição: Desenvolvimento de um layout multi-colunas totalmente adaptável utilizando HTML5 semântico e CSS Flexbox/Grid, garantindo excelente experiência visual em desktops e dispositivos móveis.

Competências aplicadas: Estruturação web, tipografia, paletas de cores e design responsivo.

2. Estilização Avançada de Formulários

Descrição: Criação e customização de formulários de cadastro e contato focados em usabilidade (UX), aplicando estados interativos com seletores avançados de CSS.

Competências aplicadas: Folhas de estilo, interatividade visual e usabilidade de inputs.

3. Página de Portfólio Pessoal

Descrição: Estruturação e desenvolvimento desta própria página web para exibição de competências técnicas, histórico acadêmico e projetos do curso.

Competências aplicadas: Organização de código-fonte, navegação interna por âncoras e boas práticas de desenvolvimento front-end.
